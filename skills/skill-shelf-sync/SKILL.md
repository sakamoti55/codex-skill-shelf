# Skill Shelf同期

Skill Shelfのリポジトリは `/Users/kose/Documents/Codex/2026-09-15/token/work/skill-studio` にある。個人スキルは `/Users/kose/.codex/skills` にある。

ユーザー自身のスキルを作成または更新した後は、次を行う。

1. skill-creatorの検証ツールで、変更したスキルを検証する。
2. 自作Skillの説明、見出し、本文、UI表示文が原則として日本語であることを確認する。英語の説明文が残っている場合は、意味と制約を保って日本語へ直してから同期する。Skill名、コード、コマンド、API名、ファイルパスなどの識別子は英語のままでよい。
3. 新しく自作したスキルの場合は、Skill Shelfリポジトリの `owned-skills.json` にスキル名を追加する。ユーザーが作成していない既存・導入済みスキルは追加しない。
4. Skill Shelfリポジトリで `npm run sync:skills` を実行する。`owned-skills.json` に記載されたスキルだけを `skills/` へコピーし、サイトの一覧データを再生成する。
5. Gitの差分を確認する。秘密情報、キャッシュ、仮想環境、ビルド成果物、無関係なファイルを含めない。
6. サイトをビルドする。
7. スキルと一覧データの変更を、簡潔なメッセージでコミットして設定済みのGitリモートへプッシュする。
8. ユーザーがローカル限定を希望していなければ、`main` へのpush後にGitHub Actionsの `Skill Shelf CI/CD` を確認する。デプロイ設定が有効ならCloudflare Workersへの自動反映まで待つ。資格情報または有効化設定が不足している場合は、リポジトリ同期まで完了し、サイト反映が保留であることを伝える。公開範囲やドメインを勝手に変更しない。

リポジトリは、自作スキルだけを保管する履歴付きミラーである。`.system`、プラグイン管理のキャッシュ、ユーザーが作成していない導入済みスキルはコピーしない。対象スキルについては、`agents`、`references`、`scripts`、`assets` を含むフォルダ全体を保持する。
